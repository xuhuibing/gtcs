## 操作指南

- **保存上下文**：当我在不同电脑上工作时，只需 git pull 最新代码，Claude 会自动加载 `.claude/` 下的项目记忆
- **更新记忆**：如果发现记忆过时了，可以让我更新对应的 `memory/*.md` 文件
- **不在 git 时**：记忆不会自动同步，需要手动复制 `.claude/` 目录
