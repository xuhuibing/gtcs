核心业务工作流

1

产品需求输入

上游业务人员录入产品信息、目的国、贸易条款

2

HS 归类推荐

匹配预裁定数据库 + 税则关键词搜索，推荐 HS 编码及税率

3

关务确认

关务同事审核 HS 编码，确认归类依据，保存记录

4

成本分析

自动计算关税、VAT、认证费用，多原产国对比

5

报关单管理

生成报关数据，状态追踪，审计留痕

功能模块一览

📊仪表盘

全局 KPI 看板：关税数据量、筛查统计、企业/产品数、审计时间线

GET /dashboard/stats

🔍税则查询

按 HS 编码、关键词查询各国关税税率，章节浏览、FTA 优惠税率

GET /tariff/lookup

🏷️HS 归类工作台

企业级归类流程：产品需求 → 预裁定匹配推荐 → 关务确认 → 税率快照

POST /hs-classification/enterprise/recommend

💰成本模拟器

进口到岸成本计算：FOB→运费→保费→CIF→关税→VAT→总成本，支持多原产国对比

POST /cost/enterprise-simulate

🤝FTA 优惠推荐

基于原产国和 HS 编码，自动匹配适用的自由贸易协定及优惠税率

GET /fta/recommend

🌍原产地判定

RVC 计算、CTC 税则归类改变检查、原产地证书管理

POST /origin/rvc/calculate/{id}

📋报关单管理

报关单创建、状态流转（草稿→申报→放行）、要素检查、审计日志

POST /declaration/create

🚫制裁名单筛查

模糊匹配引擎（difflib），FTS5 全文本搜索，筛查日志留痕

POST /screening/check

⚠️价格风险监控

申报价格与基准价对比，阈值告警，价格异常追踪

POST /price-risk/record

🏢企业管理

企业信息维护、统一社会信用代码、资质管理

GET /enterprise/list

📦产品管理

产品库维护、HS 编码关联、产品档案管理

POST /product/create

📜审计日志

全操作审计追踪，按操作类型/资源类型筛选，合规留痕

GET /audit/logs

🚀 演示亮点：HS 归类工作台

从产品需求输入到 HS 确认，全程 2 步完成，背后智能匹配预裁定数据库 + 关税税率。

步骤操作结果
1. 推荐 输入产品信息 + 目的国
如："85英寸触摸显示屏 内置计算机模块" → 目的国 CN 		返回 HS 候选列表
✓ 85285200 交互式智能平板 — 匹配预裁定 CN-2024-852852-001
2. 确认 选择 HS 编码，点击确认归类 保存归类记录 + 税率快照
✓ 记录状态 ACTIVE
预裁定匹配效果： "交互式智能平板" → 852852 | "5G CPE无线终端" → 851762 | "工控机" → 847141
覆盖国家： 中国、美国、欧盟（德国）、越南、日本
下一环节： 确认归类后可跳转至成本分析，自动计算关税 + VAT + 认证费用

⚡ 快速启动

# 后端
cd backend
pip install -r requirements.txt
python3 -m uvicorn app.main:app --reload

# 前端（开发模式）
cd frontend
npm install
npm run dev

# 访问 http://localhost:5173
